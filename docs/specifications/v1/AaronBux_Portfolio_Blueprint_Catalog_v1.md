# AaronBux Portfolio Blueprint Catalog v1

## Purpose

A Portfolio Blueprint defines the internal architecture of a recommended portfolio.
Unlike a Portfolio Archetype (investment philosophy), a Blueprint describes **how
the portfolio is constructed**.

Architecture

Investor Stage
→ Behavioral Modifier
→ Investment Style
→ Portfolio Archetype
→ Portfolio Blueprint
→ Operating Rules

- Optional

5. Opportunity Sleeve

- Optional

- Real purchasing power
- Optional

- Optional

## Blueprint Rules

Blueprint determines:
- Portfolio component structure
- Component roles
- Future allocation engine
- Portfolio explanations

Blueprint never determines:
- Specific ETFs
- Specific securities
- Exact percentages

Those are generated later by the recommendation engine.

## Acceptance Criteria

- Every Archetype maps to one default Blueprint.
- Components have explicit roles.
- Blueprints are security-agnostic.
