# AaronBux Operating Rules Catalog v1

## Purpose

Operating Rules define **how a portfolio should be managed after onboarding**.
Unlike the Portfolio Blueprint, which defines portfolio structure, Operating Rules
govern ongoing behavior, reviews, alerts, and decision-making.

Architecture

Investor Stage
→ Behavioral Modifier
→ Investment Style
→ Portfolio Archetype
→ Portfolio Blueprint
→ Operating Rules

---

# Rule Categories

## 1. Contribution Rules
Purpose:
Define how new money enters the portfolio.

Examples:
- Follow target allocation
- Fill underweight components first
- Prioritize long-term holdings

---

## 2. Review Rules

Determine when the investor should review the portfolio.

Review cadences:
- Quarterly
- Semi-annually
- Annually

Avoid excessive monitoring.

---

## 3. Rebalancing Rules

Purpose:
Maintain portfolio alignment.

Rules:
- Rebalance only when drift exceeds thresholds
- Prefer contributions before selling
- Minimize unnecessary transactions

---

## 4. Opportunity Rules

Applies primarily to Tactical Opportunist.

Rules:
- Opportunity Sleeve only
- Never alter Core Growth allocation
- Cap exposure
- Review before adding new ideas

---

## 5. Risk Guardrails

Examples:
- Diversification reminders
- Concentration warnings
- Liquidity checks
- Goal alignment checks

---

## 6. Decision Journal Rules

Prompt investors to capture:
- Why this decision?
- Expected outcome
- Time horizon
- Success criteria

---

## 7. Coaching Rules

Adjust AI guidance based on:
- Investor Stage
- Behavioral Modifier
- Investment Style

# Archetype Mapping

Balanced Family Office
- Low maintenance
- Annual review

Growth Diversifier
- Semi-annual review

Focused Compounder
- Quarterly review

Tactical Opportunist
- Monthly opportunity review
- Quarterly portfolio review

Income Preserver
- Income review
- Annual allocation review

---

## Operating Rules never determine

- Specific ETFs
- Security selection
- Portfolio allocation

Those remain responsibilities of the recommendation engine.

## Acceptance Criteria

- Every Portfolio Blueprint maps to one default Operating Rules profile.
- Rules remain explainable.
- Rules minimize unnecessary portfolio changes.
