# AaronBux Investor Stage Catalog v1

## Purpose
Investor Stage represents where an investor is in their capability journey. It affects coaching, explanation depth, learning, and feature progression—not portfolio allocation.

## Architecture
Stage -> Investment Style -> Portfolio Archetype -> Portfolio Blueprint -> Operating Rules

## Stages

### 1. Foundation Builder
- Purpose: Build a repeatable investing habit.
- Next: Portfolio Organizer
- Compatible Styles: Guided Autopilot, Steady Steward
- Coaching: Educational, reassuring.

### 2. Portfolio Organizer
- Purpose: Organize existing investments into one coherent system.
- Next: System Builder
- Compatible Styles: Guided Autopilot, Steady Steward, Systematic Improver

### 3. System Builder
- Purpose: Replace instinct with repeatable rules.
- Next: Intentional Optimizer
- Compatible Styles: Steady Steward, Systematic Improver, Bounded Explorer

### 4. Intentional Optimizer
- Purpose: Improve an existing investment system.
- Next: Adaptive Investor
- Compatible Styles: Systematic Improver, Bounded Explorer

### 5. Adaptive Investor
- Purpose: Adapt deliberately while preserving principles.
- Compatible Styles: Bounded Explorer, Active Navigator

## Resolution Rules
Investor Stage affects:
- Explanation depth
- Coaching
- Learning path
- Feature sequencing

Investor Stage never directly affects:
- Portfolio archetype
- Allocation
- Risk level
