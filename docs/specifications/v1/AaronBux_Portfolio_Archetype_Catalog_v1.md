# AaronBux Portfolio Archetype Catalog v1

## Purpose

A Portfolio Archetype defines the long-term investment system that best fits an
investor. It is independent of Investor Stage and Investment Style.

Architecture

Investor Stage
→ Behavioral Modifier
→ Investment Style
→ Portfolio Archetype
→ Portfolio Blueprint

---

# 1. Balanced Family Office (BFO)

Purpose
Create resilient long-term wealth through broad diversification.

Optimizes for
- Stability
- Consistency
- Multi-goal investing

Trade-offs
- Less upside chasing
- Fewer tactical moves

Typical investor
Long-term wealth builders.

Compatible Styles
- Guided Autopilot
- Steady Steward

---

# 2. Growth Diversifier (GD)

Purpose
Balance long-term growth with broad diversification.

Optimizes for
- Growth
- Diversification

Trade-offs
- Moderate volatility

Compatible Styles
- Steady Steward
- Systematic Improver

---

# 3. Focused Compounder (FT)

Purpose
Concentrate on a smaller number of high-conviction investments.

Optimizes for
- Long-term compounding
- Conviction

Trade-offs
- Higher concentration risk

Compatible Styles
- Systematic Improver
- Bounded Explorer

---

# 4. Tactical Opportunist (TO)

Purpose
Maintain a disciplined core while allocating a limited sleeve to opportunities.

Optimizes for
- Flexibility
- Tactical opportunities

Trade-offs
- Higher effort requirement

Compatible Styles
- Bounded Explorer
- Active Navigator

---

# 5. Income Preserver (IP)

Purpose
Generate dependable income while preserving capital.

Optimizes for
- Cash flow
- Capital preservation

Trade-offs
- Lower long-term growth

Compatible Styles
- Guided Autopilot
- Steady Steward

---

## Resolution Rules

Archetype is determined after:
- Investor Stage
- Behavioral Modifier
- Investment Style

Inputs:
- Portfolio job
- Goals
- Time horizon
- Beliefs
- Effort
- Stress response

Archetype influences:
- Portfolio Blueprint
- Explanation copy
- Portfolio diagnostics

Archetype never changes:
- Investor Stage
- Behavioral Modifier

## Acceptance Criteria

- Exactly one primary archetype.
- Optional secondary influence allowed.
- Every archetype maps to one default Portfolio Blueprint.
