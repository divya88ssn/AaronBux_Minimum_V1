# AaronBux Explanation Catalog v1

## Purpose

The Explanation Engine translates the resolver output into clear, trustworthy,
personalized guidance. It explains *why* AaronBux reached each recommendation,
rather than simply presenting results.

Architecture

Resolver Output
→ Explanation Engine
→ User Result Screens

---

# Explanation Principles

1. Explain, don't prescribe.
2. Build confidence, not dependence.
3. Focus on fit rather than performance.
4. Use plain language before financial terminology.
5. Acknowledge uncertainty when appropriate.

---

# Explanation Layers

## Layer 1 — Summary

A concise explanation of the overall assessment.

Example:
"Your answers suggest you value building a dependable long-term investment
system with moderate involvement."

---

## Layer 2 — Investor Stage

Explain:
- Current capability
- Why this stage fits
- Next capability to develop

---

## Layer 3 — Behavioral Modifier

Explain:
- Decision tendencies
- Strengths
- Potential blind spots

Avoid labeling behavior as good or bad.

---

## Layer 4 — Investment Style

Explain:
- Preferred operating model
- Expected review cadence
- Time commitment

---

## Layer 5 — Portfolio Archetype

Explain:
- Why this philosophy fits
- What it optimizes for
- What trade-offs it intentionally accepts

---

## Layer 6 — Portfolio Blueprint

Explain:
- Role of each portfolio component
- Why each component exists
- Relationship between components

Do not discuss specific ETFs or securities.

---

## Layer 7 — Operating Rules

Explain:
- Review schedule
- Contribution approach
- Rebalancing philosophy
- Opportunity rules

---

# Confidence Messaging

High Confidence
- "Your answers consistently point toward this recommendation."

Medium Confidence
- "Most of your answers align with this recommendation."

Low Confidence
- "Your answers reflect multiple investing preferences. This recommendation is a starting point that can evolve."

## Acceptance Criteria

- Every resolver output produces a complete explanation.
- Language remains non-judgmental.
- Recommendations are explainable.
- Confidence messaging is consistent.
